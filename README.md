# cv.cm

Browser tools plus a tiny cloud clipboard.

图片工具在浏览器里运行，文件不上传。云剪切板把文字存进 Cloudflare D1，查看 10 次或超过 1 天自动删除，无需登录。

## Games

Retro emulator games in the browser, grouped by console and genre. Cheats (金手指), a short walkthrough, and FAQ on every game page. Play uses [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) cores on S3. Shiru freeware (Alter Ego, Lawn Mower) starts immediately. Commercial dumps are not hosted — load a ROM you already have; it stays in this tab.

## Develop

```
npm install
npm test
npm run dev
```

Open http://localhost:5173/ — the client picks a language from the browser and sends you to `/{locale}/`.

Clipboard API calls need the Worker + D1 (`npm run deploy` or `npx wrangler pages dev dist`).

## Deploy

```
npm run build
npx wrangler d1 migrations apply cvcm --remote
npm run deploy
```

Production: https://cv.cm
