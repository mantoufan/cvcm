## 项目说明（粘贴到富文本编辑器，按「标题 / 加粗 / 列表 / 图片」排版）

### 为什么做

办银行卡、租房、入职、报名，经常要把身份证照片发给别人。原图一旦外泄，就可能被拿去注册、借贷。常见的在线加水印工具大多要先上传照片，等于把证件又交给了一个陌生服务器。

安心水印只做一件事：**让证件照在离开你手机/电脑之前，先变成「只能用于这一件事」的副本。**

### 能做什么

- **一键证件防盗用**：自动斜铺「仅供XX办理使用，他用无效 + 当天日期」，文字压过头像，难裁难去。
- **拖框打码**：在预览上拖框，证件号、银行卡号、二维码用黑块，人脸、车牌用马赛克；可撤销、每张图各自记住。
- **批量处理**：一次拖入多张，单张下载或打包 ZIP。
- **店铺/作品水印**：角落署名、居中淡印、Logo 水印，可调字体、大小、透明度、旋转、位置。
- **导出去 EXIF**：导出的新图不带拍摄时间、GPS 定位等元数据。

### 设计思路

1. **隐私第一**：所有处理都在浏览器 Canvas 里完成，没有上传接口，关掉页面即丢弃。
2. **马赛克是真替换**：被遮区域按方块取平均值后写回像素，导出的图里原始像素已不存在，不是盖了一层半透明图层。
3. **诚实提醒**：颗粒太细的马赛克仍可能认出数字，所以工具里直接提示「证件号用黑块」，教程里放了细马赛克 / 粗马赛克 / 黑块的对比图。
4. **零门槛**：没有自己的证件也能点「用示例证件试试」；第一次放入图片自动套用「证件防盗用」，并选中 XX 方便直接改写。

### 使用方法

1. 打开 cv.cm/zh-cn/watermark，拖入或粘贴身份证照片。
2. 把水印里的「XX」改成对象和用途，例如「仅供办理XX银行卡使用」，保留日期。
3. 打开「打码」，选「黑块」，拖框盖住对方不需要的栏位。
4. 下载后放大到 100% 检查：水印压过头像且看得清，姓名仍能辨认。

### 注意

水印能降低盗用风险，但不是法律保证；部分窗口仍要求无水印复印件，请先确认。

### 开发方式

借助 AI 编程助手完成设计、编码、多语言文案与测试，支持简体中文、繁體中文、English、日本語、한국어、Tiếng Việt、Bahasa Indonesia、Español 8 种语言。
